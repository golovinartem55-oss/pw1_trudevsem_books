## Что сделано

**Шаг 1–1.1.** Окружение, параметры варианта 10, вежливый HTTP-клиент с ретраями и кэшем.

**Шаг 2. Сбор через REST API.**
- Пагинация trudvsem: 4 страницы, собрано **51 вакансия**;
- обработка ошибок, пауза 0.5 с между запросами, кэш на диск;
- приведение вложенного JSON к плоской таблице (`df_api`): название, компания, регион, зарплатная вилка, требования.

**Шаг 3. Парсинг HTML.**
- Сбор двумя независимыми способами: BeautifulSoup (CSS) и lxml (XPath);
- **32 книги** в категории `mystery_3`, совпадение BS4 и XPath — **32 из 32**;
- причина: в категории `mystery_3` физически 32 книги, минимум по заданию (40) недостижим.

**Шаг 4. Очистка регулярными выражениями.**
- Функции `parse_price`, `parse_stock`, `parse_rating`, `parse_salary`, `extract_skills`;
- автотесты `CASES` пройдены;
- **100 %** распознано: цена, наличие, рейтинг, зарплата; извлечено **41 упоминание навыков** из требований.

**Шаг 5. Разведочный анализ.**
Четыре графика по метрикам варианта 10:
1. Доля out-of-stock в каталоге книг (0 % — все в наличии).
2. Распределение цен (медиана 25.38 £, IQR 29.36 £).
3. Топ-10 регионов по числу вакансий (лидер — Пензенская область, 12).
4. Boxplot зарплатных вилок по топ-6 регионам (общая медиана 78 200 ₽).

**Шаг 6. Метрики и выводы.**
- 51 вакансия, 32 книги;
- доля удалённых вакансий — 0 %;
- честно указаны ограничения: 32 < 40, флаг наличия вместо числа остатков.

## Самопроверка

**10 из 11 пунктов** пройдено. Единственный непройденный — «Собраны данные парсингом (≥ 40 карточек)»: в категории `mystery_3` сайта `books.toscrape.com` физически 32 книги, минимум недостижим.

## Как воспроизвести

1. Открыть ноутбук в Google Colab или локальном Jupyter.
2. Убедиться, что в шаге 1 стоит `VARIANT = 10`.
3. `Среда выполнения → Выполнить все`.
4. Дождаться прохождения всех ячеек.
5. Самопроверка в конце покажет результат.

**Примечание.** Для повторного сбора с реальными запросами (не из кэша) установите `USE_CACHE = False` в шаге 1 и удалите папку `pw1_cache`.

## Ограничения

- **Категория `mystery_3` содержит 32 книги** — минимум 40 карточек недостижим.
- **books.toscrape.com не отдаёт число остатков** — только флаг `'In stock'` / `'Out of stock'`.
- **Trudvsem по запросу «категорийный менеджер»** даёт 51 вакансию — другие формулировки могли бы дать больше.
- **Разовый срез** — данные отражают состояние источников на дату запуска.
